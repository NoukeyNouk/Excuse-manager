# Excuse-Manager

Данный сервис предназначен для создания креативных и правдоподобных извинений. Например:

* Вы играли в доту всю ночь но хотите получить 5 за экзамен
* Вам стало лень ехать на работу, но не хотить увольняться
* Вы обещали жене цветы, но пиво оказалось слишком дорогим

### Запуск

Благодаря пакетному менеджеру `uv` все зависимости подтягиваются при первом запуске.

```bash
make
```

### ИИ-агент

В качестве ИИ-агента используется Google-gemini, для корректной работы которого нужна виртуальная приватная сеть. В `.env.example` находится пример API-токена для работы программы.
